# Guide Des Graphes Chronos FPA

Point d'entree pour comprendre les figures generees par `--visualisation`.

Lire :

```text
docs/graphes/CHRONOS_FIGURES_GUIDE.md
```

Les figures standard sont dans :

```text
result/NOM_DU_RUN/figures/
```

Les figures plus exploratoires/recherche sont dans :

```text
result/NOM_DU_RUN/figures/recherche/
```
